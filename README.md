# Movie Ratings Analysis Using Singular Value Decomposition (SVD)

## Project Overview

This project explores Singular Value Decomposition (SVD) as a matrix factorization technique for analyzing movie rating data.

The analysis uses a 20 × 50 user-movie rating matrix to investigate patterns in user preferences, understand singular values and vectors, and evaluate low-rank approximations.

## Objectives

- Explore movie rating distributions using statistical analysis and visualizations.
- Apply Singular Value Decomposition to the rating matrix.
- Interpret singular values and singular vectors.
- Analyze the first three components and identify potential patterns.
- Reconstruct the original matrix using low-rank approximations.

## Dataset

- 20 users
- 50 movies
- Ratings ranging from 1 to 5
- No missing values

## Methods

- Exploratory Data Analysis
- Heatmap Visualization
- Singular Value Decomposition (SVD)
- Singular Value Analysis
- Component Interpretation
- Low-Rank Matrix Approximation
